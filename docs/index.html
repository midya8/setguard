02 / KEEP THE QUESTION FIXED

Choose a case, not a guarantee.

α changes rank arithmetic, not the fixed classifier or supplied data. Exploring α on this page is descriptive, not a label-driven tuning procedure. Candidate labels are not used for fitting.

03 / THE CORRECTED ORDER STATISTIC

Count positions. Keep the ties.

Scores are 1 − p(true label). The exact decimal-α rank is ceil((n + 1)(1 − α)). If it exceeds n, the threshold is infinity: every candidate class is included. Sorting by original row index only stabilizes the display of ties; it never splits equal scores.

04 / EVERY LABEL GETS A REASON

The score meets the threshold.

Pooled calibration uses one threshold. Classwise calibration uses only rows with that true label. Rare or absent classes can force inclusion, with no pooled fallback. A label on the boundary is included by ≤, not discarded to match the rank count.

06 / A FINITE RANK CHECK
Hold out positions, not assumptions.
Each calibration position becomes the held-out score once. The remaining positions determine its threshold. This deterministic count checks rank logic, including ties. It neither tests exchangeability nor estimates uncertainty, validation error or coverage for this realized candidate. A group needs at least two positions.

08 / KEEP THE SCOPE WITH THE RESULT
Marginal is not individual.
The standard guarantee averages over exchangeable calibration and fresh test scores for a predictor fixed independently of calibration. Pooled marginal coverage does not promise each label, input, fixed calibration split or deployment. Classwise coverage needs exchangeability within true label; it is not input-conditional coverage or protection under distribution shift. JSON validation cannot verify these assumptions.
Exact decimal rank arithmetic does not make binary64 probabilities exact real numbers. A tie at a floating-point boundary is a numerical equality; the implementation does not certify forward error. No new statistical method, adaptive scoring, clustered conformal, randomized tie-breaking or online calibration.
